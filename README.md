# Лабораторная работа №3

Веб-приложение для создания, просмотра, обновления и удаления конфиденциальных и неконфиденциальных данных.

## Запуск

```powershell
python -m pip install -r requirements.txt
python -m uvicorn src.main:app --reload
```

Откройте в браузере `http://127.0.0.1:8000`.

Публичные записи хранятся в памяти как обычный текст. Название и содержимое конфиденциальных записей перед помещением в in-memory репозиторий шифруются Fernet. Ключ создаётся при запуске, поэтому после завершения или перезапуска приложения все данные исчезают.

Авторизация, пользователи, access-токены, cookies и база данных отсутствуют.

Архитектура разделена на слои `domain`, `application`, `infrastructure`, `api` и `presentation`.

## Анализ памяти и CPU

Для запуска benchmark-теста выполните:

```powershell
python scripts/run_performance_test.py
```

Результаты сохраняются в `analysis/performance_results.csv` и `analysis/performance_results.md`. Тест выполняет пять независимых запусков, в каждом создаёт 100 неконфиденциальных и 100 конфиденциальных записей, а затем измеряет чтение, обновление и удаление данных.

Для автоматического создания трёх дампов памяти на Windows:

```powershell
python scripts\run_memory_dump_test.py
```

Дампы сохраняются в `analysis/dumps`: после создания, обновления и удаления публичной и конфиденциальной записей. Скрипт использует Windows API `MiniDumpWriteDump` и не требует отдельной установки ProcDump.

Тест также создаёт неконфиденциальную запись и автоматически сохраняет результаты поиска контрольных строк в `analysis/memory_strings_analysis.md`.
